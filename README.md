## 運用方針

- **GitHubを設定と本文の正本**として扱います。
- 設定は4ファイルに集約。ChatGPTのプロジェクト情報源には必要な設定資料を選んで追加します（自動同期は前提にしません）。
- 本文は**1章1ファイル**です。章をまたぐ統合版は必要時に生成し、二重管理しません。
- **確定した設定**、**執筆済み本文で描写された内容**、**未執筆章の構想**を区別します。矛盾を独断で埋めず確認対象として記録します。
- 元会話からの整理では、明示的な後続修正を初期案より優先します。
